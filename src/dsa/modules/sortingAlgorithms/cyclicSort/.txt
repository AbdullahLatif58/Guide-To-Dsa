Cyclic Sort

What is Cyclic Sort?

Cyclic Sort is not a general-purpose sorting algorithm. It is a special algorithm used when every number has a fixed correct index.

It works by repeatedly placing each number into its correct position instead of comparing every element with every other element.

⸻

When should I use Cyclic Sort?

Use it only when the problem guarantees one of these conditions:

* Numbers are from 0 to n
* Numbers are from 1 to n

Every value must have a valid destination (correct index).

Examples:

[3,1,2]
[4,3,2,1]
[0,3,1]
[4,3,2,7,8,2,3,1]

Do not use it for arrays like:

[8,9,1,4]
[100,20,5]

because those numbers do not have valid indexes inside the array.

⸻

How do we find the correct index?

Case 1: Numbers are from 0 to n

Value 0 → Index 0
Value 1 → Index 1
Value 2 → Index 2

Formula:

correct = arr[i];

⸻

Case 2: Numbers are from 1 to n

Value 1 → Index 0
Value 2 → Index 1
Value 3 → Index 2

Formula:

correct = arr[i] - 1;

We subtract 1 because array indexes start at 0.

⸻

Core Idea

For every element:

1. Look at the current number.
2. Calculate where it belongs.
3. If it is not already there, swap it with the element at its correct position.
4. Repeat until every possible number is in its correct place.

⸻

Example

Input:
[3,5,2,1,4]
i = 0
Current value = 3
Correct index = 3 - 1 = 2
Swap:
[2,5,3,1,4]
Again at i = 0
Current value = 2
Correct index = 2 - 1 = 1
Swap:
[5,2,3,1,4]
Again at i = 0
Current value = 5
Correct index = 5 - 1 = 4
Swap:
[4,2,3,1,5]
Continue until every value reaches its own position.

⸻

Why is it useful?

Cyclic Sort is mainly used to solve problems like:

* Find the missing number
* Find all missing numbers
* Find duplicate numbers
* Find all duplicate numbers
* Find the first missing positive
* Find the corrupt pair (one duplicate and one missing)

Notice that these are finding problems, not normal sorting problems.

⸻

Time Complexity

O(n)

Each element is moved to its correct position at most once.

⸻

Space Complexity

O(1)

No extra array or hash map is required.

⸻

One Sentence to Remember

“Cyclic Sort places every number into its correct index. After all possible numbers are in their correct positions, any incorrect position reveals the missing or duplicate values.”
